# Veylora Drive

## Premium Car Rental Website

Veylora Drive is a modern car rental website developed to provide users with a simple and convenient platform for exploring rental vehicles and submitting booking requests.

The project focuses on a clean user interface, responsive design, vehicle browsing, search and filtering functionality, and an easy-to-use booking experience.

---

## Live Demo

[View Veylora Drive Live](https://nimrafatima759.github.io/veylora-drive/)

---

## Project Overview

Veylora Drive is a frontend web development project created for a car rental service.

The website provides a professional interface where users can explore available vehicles, view vehicle information, search and filter vehicles, and submit their rental details through the booking section.

The project demonstrates practical frontend development skills using HTML5, CSS3, and JavaScript, along with deployment through GitHub Pages.

---

## Features

### Vehicle Fleet

Users can browse the available rental vehicles through the fleet section. Vehicle cards provide relevant information such as:

* Vehicle name and model
* Vehicle category
* Rental price
* Fuel type
* Seating capacity
* Availability status

### Search and Filtering

The website provides search and filtering functionality to help users find suitable vehicles more efficiently.

### Booking Form

Users can provide their rental information through the booking form, including:

* Full name
* Contact information
* Email address
* Selected vehicle
* Pickup date
* Return date

### Responsive Interface

The website is designed with a responsive layout to provide a consistent user experience across desktop, tablet, and mobile screen sizes.

### Customer Information

The website includes service-related information and customer statistics to present the rental service and its key benefits.

### Contact Section

A dedicated contact section provides users with relevant information for contacting the car rental service.

## Getting Started

### Prerequisites

To run the project locally, you only need:

* A modern web browser
* A code editor such as Visual Studio Code

### Run Locally

Clone the repository:

```bash
git clone https://github.com/nimrafatima759/veylora-drive.git
```

Navigate to the project directory:

```bash
cd veylora-drive
```

Open `index.html` in a web browser.

For development, the project can also be opened using the Live Server extension in Visual Studio Code.
