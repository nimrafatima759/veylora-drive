# Veylora Drive

## Premium Car Rental Website

Veylora Drive is a modern car rental website developed to provide users with a simple and convenient platform for exploring rental vehicles and submitting booking requests.

The project focuses on a clean user interface, responsive design, vehicle browsing, search and filtering functionality, and an easy-to-use booking experience.

## Project Overview

Veylora Drive is a front-end web development project created for a car rental service. The website presents a professional interface where users can explore available vehicles, view relevant vehicle information, and submit their rental details.

The project demonstrates the implementation of a responsive website using HTML, CSS, and JavaScript, along with deployment through GitHub Pages.

---

## Features

### Vehicle Fleet

Users can browse the available vehicles through the fleet section. Each vehicle is presented with relevant information such as:

* Vehicle name and model
* Vehicle category
* Rental price
* Fuel information
* Seating capacity
* Availability status

### Search and Filtering

The website provides search and filtering functionality to help users find suitable vehicles more efficiently.

### Booking Form

Users can provide their rental information through the booking form, including:

* Full name
* Contact information
* Email address
* Selected vehicle
* Pickup date
* Return date

### Responsive Interface

The website is designed to provide a consistent user experience across desktop and smaller screen sizes.

### Customer Information

The website includes service-related information and customer statistics to communicate the overall value and reliability of the rental service.

### Contact Section

A dedicated contact area provides users with relevant information for getting in touch with the rental service.

## Getting Started

### Prerequisites

To run the project locally, you only need:

* A modern web browser
* A code editor such as Visual Studio Code

### Run Locally

Clone the repository:

```bash
git clone https://github.com/nimrafatima759/veylora-drive.git
```

Navigate to the project directory:

```bash
cd veylora-drive
```

Open `index.html` in a web browser.

For development, the project can also be opened using the Live Server extension in Visual Studio Code.
